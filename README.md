- HTML5
- CSS3
- JavaScript
- LocalStorage

Fui responsável pelo desenvolvimento da área de Produtos e Categorias do projeto, trabalhando na organização e apresentação dos produtos e nas funcionalidades relacionadas à categoria.

🔗 [Acessar repositório](https://github.com/Melibanio/PetShop)
